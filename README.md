# 마이크로비트 온도 탐구실 v1.2.2 — 학생용 링크 및 QR 코드

## 이번 업데이트

- 데이터 관리/실험 설정의 `실험 ID 복사` 버튼 → **학생용 링크 복사**로 변경
- **QR 코드 생성** 버튼 추가: 현재 선택된 실험의 조회 링크를 QR로 만들어 팝업 표시
- 팝업: QR 이미지, 실험명, 전체 URL, 링크 복사, **QR 이미지 PNG 저장**, 닫기
- 학생용 Apps Script 기본 주소를 `config.js`의 `studentViewerUrl`에 설정
- QR 생성은 웹브라우저에서 자체 실행됩니다. 외부 QR 사이트에 실험 ID나 URL을 전송하지 않습니다.
- 기존 웹 시리얼·IndexedDB·구글 시트 동기화·그래프 기능은 변경하지 않음

## 설치

압축파일 속 다음 다섯 파일을 기존 GitHub 저장소 최상단에 업로드/덮어쓰기하세요.

1. `index.html`
2. `style.css`
3. `app.js`
4. **`qr-local.js` (새 파일이므로 반드시 함께 업로드)**
5. **`config.js` (주소 2개 확인 후 업로드)**

`config.js`에 지정된 `gasUrl`은 기존에 공개된 GitHub 저장소의 교사용 서버 주소를 유지한 것입니다. 교사용 서버 URL을 최근 변경했다면 기존 `config.js`의 `gasUrl`을 다시 사용하세요. 새 `studentViewerUrl`에는 요청하신 학생용 Apps Script URL을 미리 넣었습니다.

> 업데이트 후 기존 실험 기록이 사라지지 않도록 동일한 GitHub Pages 주소/브라우저 프로필에서 실행하세요. 로컬 기록과 구글 시트 데이터는 이 업데이트로 삭제되지 않습니다.

### QR 사용 방법

1. 교사용 페이지 → **데이터 관리 및 실험 설정** 펼치기
2. `이전 실험 불러오기`에서 원하는 실험 선택 (또는 새 실험 시작)
3. `학생용 링크 복사`를 클릭하면 `studentViewerUrl?session=실험ID` 형식으로 복사
4. `QR 코드 생성`을 클릭하면 QR 팝업 표시
5. 학생이 스마트폰 카메라로 스캔 → 해당 실험만 조회

학생용 화면에 측정값이 나타나려면 **해당 실험의 구글 시트 동기화가 완료**되어야 합니다.

### 수업 교사에게 유용한 기능

- QR 팝업을 교실 화면에 투사해 학생이 바로 스캔할 수 있습니다.
- QR 이미지 저장 버튼으로 학급 알림장·수업자료에 PNG 이미지를 넣을 수 있습니다.
- QR에는 실험 ID가 포함됩니다. 이를 받은 사람은 해당 공개 실험을 조회할 수 있으니 수업 범위 내에서 공유하세요.

## 점검

- 페이지 하단 `v1.2.2` 표시 확인 (안 바뀌면 GitHub Actions 배포 및 Ctrl+Shift+R 새로고침)
- QR 버튼에 반응이 없으면 `qr-local.js`가 업로드되었는지 확인
- 교사용 동기화가 안 되면 `config.js`의 **gasUrl** 값을 이전 설정과 비교
- 학생 페이지가 열리지 않으면 `studentViewerUrl`과 Apps Script 웹 앱 배포/공개 설정 확인
- 학생 페이지에 값이 없으면 실험 ID와 교사용 시트 업로드 상태 확인
