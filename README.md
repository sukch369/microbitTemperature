# 마이크로비트 온도 탐구실 · 교사용 GitHub Pages v1.2.1

버전: **v1.2.1 (2026-10-21)**  
기반: v1.1 교사용 수집 프로그램. **기존 IndexedDB 실험 기록과 Google Apps Script 저장 API를 그대로 사용합니다.**

## v1.2.1 변경사항 (이번 패치)

1. **MISS 구간 연결:** 35초 이상 간격이 생기면 끊던 로직을 변경했습니다. 누락 구간 앞뒤에 실제 수신한 점이 있으면 해당 두 점을 **점선으로 연결**합니다. 중간 임의 온도는 생성하거나 저장하지 않습니다.
2. **같은 온도의 두 선 모두 표시:** A와 B 온도가 같고 수신 시각이 가까운 경우(15초 이내), 화면상 좌표만 **A 약 2.5px 위 / B 약 2.5px 아래**로 나란히 표시합니다. 실제 온도값과 CSV/시트 기록은 전혀 바꾸지 않습니다.
3. **기존 기능 유지:** 첫 측정~마지막 측정 전체 시간, Y축 정수 온도, USB/IndexedDB/시트 동기화 및 구버전 호환 데이터 구조 유지.
4. **화면에 설명 추가:** 그래프 아래 점선과 겹선의 의미를 짧게 안내합니다.
5. **캐시 회피:** `style.css?v=1.2.1`, `app.js?v=1.2.1`로 갱신했습니다.

### v1.2에서 이어지는 주의사항

- 측정 실패(`MISS`)는 여전히 **실제 측정 기록에 추가되지 않습니다.** 선은 관찰된 앞뒤 두 점을 연결하는 시각적 보조 요소입니다.
- 긴 데이터 공백을 연결한 점선은 그 사이에 같은 변화가 있었다는 증거가 아닙니다.
- 기존 `config.js`와 `apps-script/Code.gs`를 **교체하지 마세요.** 기존 데이터 및 시트 연결을 유지해야 합니다.

## 이번 업데이트 내용

1. **교사용 수업 화면 간소화:** 처음 보이는 화면에 6모둠 A/B 현재 온도와 선택 모둠 그래프를 집중 배치했습니다. 수신 상태 및 실험명은 간단히 표시합니다.
2. **데이터 관리 하단으로 이동:** USB 연결·실험 정보, 로컬 측정값, 시트 동기화 완료/대기, 마지막 시리얼 수신, 의심값 보류, CSV 백업, 시리얼 진단, 최근 수신 기록이 **하단 `데이터 관리 및 실험 설정` 접이식 영역**에 있습니다.
3. **온도 정수 표기:** 모둠 카드·수신 기록·그래프의 온도 세로축을 소수점 없이 표시합니다. 원본 저장값을 강제로 변경하지는 않습니다. 마이크로비트 MakeCode에서 보낸 정수 값이 유지됩니다.
4. **그래프 전체 기간 표시:** 이전 코드의 `.slice(-200)` 제한을 제거하여 로컬 실험의 **첫 측정부터 마지막 측정까지** 모든 온도 기록의 선을 그립니다. X축은 수신 시각, Y축은 정수 온도(℃)입니다. 마지막 정상 측정값의 보존 및 `MISS` 미저장 원칙도 유지합니다. 기본 20초 간격에서 35초가 넘는 구간은 **점선으로 연결**하여 누락을 알립니다. 점 표식은 밀집 시 일부 생략되나 그래프 선은 전체 기록을 사용합니다.
5. **급격한 온도 변화 검증 UI 수정:** 기존 `input` 공통 스타일 때문에 체크박스가 가로로 커지던 현상을 막기 위해 고정 18px 크기와 설명 전용 영역을 설정했습니다. 검증 기준(3분 내 10℃ 초과 시 첫 1건 보류)은 변경하지 않았습니다.
6. **교사용 메뉴만 표시:** 상단 `데이터 공유` 탭은 숨겼습니다. 신규 학생용 **Google Apps Script 전용 공유 사이트는 다음 개발 단계**에서 제작합니다. 이전 GitHub `?view=share` 주소는 기존 링크 호환을 위해 임시로 작동하게 남겨두었지만, **학생의 교사용 GitHub Pages 접근을 차단하는 접근 제어 기능은 아닙니다.**
7. **실험 ID 복사:** 기존 `측정 결과 공유 링크 복사` 버튼을 `실험 ID 복사`로 변경했습니다. 학생용 Apps Script 사이트 완성 후 `실험 ID` 기반 전용 링크를 생성할 예정입니다.
8. **캐시 갱신:** `index.html`에 `style.css?v=1.2.0`, `app.js?v=1.2.0`을 사용하여 GitHub Pages 갱신 시 이전 JS/CSS가 브라우저에 남을 가능성을 줄였습니다.

## 기존 GitHub Pages 업데이트 방법

업데이트 ZIP 안의 다음 **4개 파일**을 사용하세요.

```text
index.html
style.css
app.js
README.md     (선택 업로드)
```

1. 먼저 기존 사이트에서 `데이터 관리` → `현재 실험 CSV 백업`을 실행하여 측정 기록을 보관합니다.
2. GitHub 저장소 `sukch369/microbitTemperature`의 **루트 폴더**에 `index.html`, `style.css`, `app.js`를 최신 파일로 덮어씁니다. `README.md`는 원할 때 덮어씁니다.
3. **`config.js`는 절대 교체하지 마세요.** 기존 Apps Script `/exec` 주소 및 설정을 보존해야 합니다.
4. **`apps-script/Code.gs`는 수정할 필요가 없습니다.** 기존 시트·배포도 변경하지 않습니다.
5. GitHub `Actions`에서 Pages 배포가 새 커밋 기준으로 완료되었는지 확인합니다.
6. `https://sukch369.github.io/microbitTemperature/`에서 강력 새로고침(`Ctrl + Shift + R`) 후 하단 `v1.2.1`이 표시되는지 확인합니다.
7. 처음에 `USB 연결 대기`로 보입니다. 화면 맨 아래 `데이터 관리 및 실험 설정`을 펼치고 **`USB 시리얼 연결`**을 눌러 교사용 마이크로비트를 연결합니다.

> **주의:** 같은 GitHub Pages URL과 같은 브라우저 프로필로 접속하면 IndexedDB의 기존 측정 기록은 일반적으로 유지됩니다. 다만 브라우저 저장 공간을 삭제했거나 시크릿 모드라면 그렇지 않습니다.

## 수업 중 이용

- 첫 화면: **전체 모둠 온도 현황** → 원하는 모둠 클릭 → **모둠별 전체 기간 온도 변화 그래프**.
- 실험명 변경/기존 실험 전환/새 실험 만들기: 하단 `데이터 관리 및 실험 설정` 열기.
- 30초 간격 자동 구글 시트 동기화는 이전처럼 계속 수행됩니다. 수동 동기화·CSV 백업·USB 연결 해제도 하단 영역에서 가능합니다.
- 학생용 Apps Script 공유 링크 배포는 **다음 단계에서 진행**합니다. 현 버전의 `실험 ID 복사`는 직접 학생에게 전달할 링크가 아니라 데이터 식별자입니다.
- MakeCode 편집기에서 교사용 마이크로비트의 WebUSB 연결을 끊고 GitHub Pages에 USB 연결하세요. 동시에 연결하면 문자 일부가 빠지는 문제가 관찰됐습니다.

## 현장 검증 권장 항목

1. 새 버전 표시(v1.2), 모둠 카드에서 `24°C` 형태의 정수 표시 확인.
2. 1모둠/4모둠 등 선택 시 상세 그래프 전환 확인.
3. 실제 200건이 넘는 **장시간 실험**을 불러와 그래프의 시작/끝 시간 확인.
4. 그래프의 세로축에 `23`, `24`, `25` 등 정수만 나타나는지 확인.
5. 하단 관리 펼침 → 체크박스가 정상 크기인지 확인.
6. USB 수신, 자동 동기화 및 CSV 백업이 기존처럼 동작하는지 확인.
7. 기존 구글 시트의 데이터나 Apps Script 주소가 변경되지 않았는지 확인.

## 다음 개발 단계 (이번 ZIP에는 포함하지 않음)

- **학생용 Apps Script 조회 전용 웹 앱**을 별도로 배포합니다. `?session=<실험 ID>`처럼 교사가 전달하는 링크로 **하나의 지정된 실험만** 조회할 수 있도록 만듭니다.
- 학생용 페이지 구성은 실험 제목, 전체 6모둠 현황, 선택 모둠 A/B 전체 기간 온도 그래프만 포함합니다. 학생용 화면에 USB 수신, 시트 업로드, 삭제 기능은 넣지 않습니다.
- 링크가 외부에 공개되면 데이터도 읽을 수 있으므로 학생 개인정보 저장을 피해야 합니다. **GitHub Pages가 공개되어 있는 동안 주소를 아는 사람이 교사용 화면을 열지 못하게 보장할 수는 없습니다.** 실제 쓰기 권한 보호는 서버 검증과 별도 인증 설계가 필요합니다.

## 기존 데이터 관련 주의

- 모든 원본 측정 데이터는 IndexedDB에 보관되고, Apps Script 동기화는 그대로 작동하도록 기존 코드 기반으로 수정했습니다.
- 현재 그래프는 주어진 데이터 전체를 표시하지만, 과거에 기록된 비정상적인 온도값은 자동 삭제되지 않습니다. 교사 확인 후 삭제 또는 새로운 실험으로 분리해 주세요.
- 오프라인 상태라도 이미 열어 둔 사이트에서 시리얼 수집과 로컬 저장은 가능합니다. 웹사이트를 새로 열거나 새로고침할 때는 인터넷이 필요할 수 있습니다.
