스프레드시트 동기화 및 백업

로컬 저장은 자동이며, 서버가 확인한 값만 동기화 완료로 처리합니다.

서버 미설정

인터넷 연결이 끊겨도 측정 기록은 이 PC의 IndexedDB에 저장됩니다. 브라우저의 사이트 데이터를 삭제하면 사라질 수 있으므로 CSV 백업을 권장합니다.

시리얼 원본 진단

교사용 마이크로비트의 REQ / RX / DATA / MISS 메시지를 확인합니다.

USB 시리얼 연결 후 원본 메시지가 표시됩니다.

보류된 값은 원본과 함께 PC IndexedDB에 기록되며, 그래프와 구글 시트 동기화에서는 제외됩니다. 기존 저장값은 자동 삭제되지 않습니다.
